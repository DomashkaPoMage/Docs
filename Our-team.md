## Правила совместной работы

- задачи регистрируются в GitHub Issues;
- состояние задач отслеживается в GitHub Projects;
- документация хранится в GitHub Wiki и репозитории Docs;
- каждое изменение сохраняется отдельным коммитом;
- сообщения коммитов должны описывать выполненное изменение.
